# Security and Ethics

## Security Foundations
- Password hashing with bcrypt.
- Role-based access controls for starter workflows.
- Least-privilege access design.
- Input validation for user-supplied data.
- File-upload extension filtering and safe filename handling.

## Ethics and Data Boundaries
- Protect patient privacy at all stages.
- Use synthetic grid data only; do not present it as official infrastructure data.
- ClinicCare-Lite is non-diagnostic and does not provide treatment recommendations.
- Avoid using real confidential data during demonstrations.
