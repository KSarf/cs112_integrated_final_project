# Diagram Assets

This directory contains the final design and workflow diagrams for the CS 112 project.

- `overall-architecture.md` — high-level relationship between the synthetic grid datasets, Grid Analysis, GridCare-Lite and the separately bounded ClinicCare-Lite application.
- `gridcare-er-diagram.md` — GridCare-Lite database entities and relationships.
- `gridcare-use-case.md` — GridCare-Lite role-based use cases and outage-to-resolution workflow.
- `cliniccare-er-class-diagram.md` — ClinicCare-Lite persistent models and their relationships.
- `cliniccare-use-case.md` — clinician/patient use cases and explicit non-diagnostic scope boundary.
- `cliniccare-data-flow.md` — ClinicCare-Lite administrative task, upload, review, notification and communication flow.

The diagrams use Mermaid syntax so they render directly in supported Markdown viewers such as GitHub.
