# Git Workflow Recommendations

- Use `main` as the stable branch.
- Use short-lived feature branches.
- Use pull-request reviews before merge.
- Track work in GitHub Issues.
- Use GitHub Projects for weekly planning.

## Commit Message Examples
- `feat: add starter network validation module`
- `fix: correct upload extension check`
- `docs: update setup instructions`
- `test: add app factory smoke test`
- `refactor: split authentication helpers`
- `chore: update pre-commit hooks`
