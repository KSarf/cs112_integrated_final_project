# Contributing Guide

Thank you for contributing to this CS 112 final project.

## Branching and Pull Requests
- Do not push directly to `main`.
- Create focused branches for each issue.
- Suggested branch prefixes:
  - `feature/`
  - `fix/`
  - `docs/`
  - `test/`
  - `refactor/`
- Open a pull request for each branch.
- Request at least one review before merge.

## Commit and Issue Hygiene
- Keep commits small and meaningful.
- Reference issue numbers in pull requests and commits where possible.
- Run checks before requesting review.
- Resolve merge conflicts carefully and retest impacted areas.

## Security and Privacy
- Do not commit secrets.
- Do not commit generated databases.
- Do not commit private patient information.
- Use only synthetic electricity-grid data for demonstrations.
